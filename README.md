# PORTIA Programming Language
### Written by: BSCS 3-3 A.Y 2025-2026 | LoomVI 
PORTIA takes its name from the Portia spider, renowned for patience, precision, and calculated strategy. In the same way the spider crafts its web with intent, PORTIA weaves rules and logic into a unified and purposeful structure.

PORTIA is a high-level, procedural, statically typed programming language built around clarity and discipline. Programs in PORTIA are written as tightly defined statements, with clear boundaries of scope and language features that emphasize order, clarity, and precision. 

Drawing inspiration from established languages, PORTIA inherits C’s procedural structure, explicit scoping between local and global contexts, and disciplined statement design. From Python, it embraces readability, consistency, and the avoidance of ambiguity as guiding principles. Meanwhile, Lua influences its intuitive approach to string handling.

As with the spider’s web, programs in PORTIA form patterns of intent: deliberate, interconnected, and purposeful.
